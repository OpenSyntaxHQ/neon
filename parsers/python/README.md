# neon-format (Python)

Python reference implementation for NEON 1.0.

## Install
```bash
pip install neon-format
```

## API
```python
from neon import loads, dumps, format_text, validate
```

## CLI
```bash
neon parse file.neon
neon format file.neon
neon validate file.neon
neon compact file.neon
```
